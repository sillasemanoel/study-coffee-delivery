# Coffee Delivery

![Preview](.github/preview.png)

Sistema de delivery de café com carrinho de compras, formulário de endereço e resumo do pedido.

## Tecnologias

• React
• TypeScript
• Vite
• styled-components
• react-hook-form
• zod
• react-router-dom
• immer

## Como Executar

```bash
npm install
npm run dev
```
